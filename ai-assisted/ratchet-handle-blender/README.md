# Ratchet Handle Concept (Blender)

A concept model of the Convoy ratchet handle: front, side and top 2D views plus a 3D model.

## Who did what
- **Idea and requirements (me):** replace preset-height pins with a ratchet; handle pushes down any time, only pulls up while holding a button on top.
- **Mechanism suggestion and model (Claude):** sawtooth rack + spring pawl, release rod with a wedge that cams the pawl out; built the Blender model and drawing sheet.

## Dimensions (cm, concept only)
- Outer tube 3.6 x 2.2, inner tube 2.2 x 1.4
- Tooth pitch 0.6, depth 0.3
- Single stage. The real handle uses 25 mm square rods, so this needs resizing when rebuilt in Fusion.

## Parts (color in 3D)
- Rack teeth (dark steel), pawl (orange), release rod (blue), button (red), springs (silver)
